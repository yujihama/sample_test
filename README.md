# 内部監査AIエージェントシステム

## システム概要

このシステムは、監査業務の自動化・効率化のためのAIエージェントによる内部監査支援システムです。
複数のAIエージェントが協調して動作し、内部監査プロセスの様々なステップを自動化・支援します。特にマルチエージェント間の連携と補助ツールの活用による効率的な監査業務の実行を特徴としています。

## 主要機能

1. **マルチエージェント連携**
   - エージェントA: 監査手続き理解・設計
   - エージェントB: サンプル検証実行
   - エージェントC: 結果集約
   - エージェントD: 報告書作成

2. **補助ツール統合**
   - 画像処理ツール: 印影検出、画像鮮明化等
   - データ照合ツール: 社員マスタとの照合、権限確認等
   - Excel解析ツール: 複数シート間のデータ解析
   - 文書解析ツール: PDFのテキスト抽出等

3. **階層的問題解決アプローチ**
   - 1層: ツールによる自動解決
   - 2層: 追加情報による解決
   - 3層: 人間の監査人への質問

## 使用技術

- **バックエンド**: Python, FastAPI
- **データベース**: PostgreSQL
- **AI/ML**: LangChain, OpenAI API
- **その他**: Pydantic, Loguru, SQLAlchemy

## セットアップと実行

### 環境構築

```bash
# 仮想環境の作成と有効化
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 依存パッケージのインストール
pip install -r requirements.txt

# データベースのセットアップ
python src/init_db.py
```

### アプリケーション実行

```bash
# 開発サーバー起動
python src/main.py

# または
uvicorn src.api.main:app --reload
```

## ユースケース

このシステムは以下のような内部監査シナリオをサポートします：

1. **監査プロセスの全体フロー**
   - 初期設定・準備フェーズ（監査基準の定義）
   - サンプル単位の処理サイクル（検証実行）
   - 階層的な問題解決プロセス

2. **具体的なユースケース例**
   - 出張精算書類の検証（印影の確認、承認者権限の検証等）
   - 取引記録の検証（複数シートにまたがるデータの整合性確認）
   - 予算変更承認の正当性検証

詳細なユースケースシナリオは `doc/ユースケース.md` を参照してください。

## 拡張ガイド

各フォルダには `README.md` ファイルが配置されており、システムの各コンポーネントの詳細な説明と拡張方法が記載されています。新機能の追加や既存機能の拡張を行う際は、まずそれらのガイドを参照してください。

### 拡張ポイント

1. **新規ツールの追加**
   - `src/tools/` に新しいツールクラスを実装
   - `config/tools_config.yaml` に設定を追加

2. **エージェント機能の拡張**
   - `src/agents/` 内の対応するエージェントファイルを修正
   - 新しいエージェントを追加する場合は基底クラスを継承

3. **新しいワークフロータイプの追加**
   - `src/core/workflow.py` にワークフロー定義を追加
   - 必要に応じてエージェント間の通信フローを設計
