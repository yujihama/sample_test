# 疎通テスト（Smoke Tests）

## 概要

このディレクトリには、システムの基本的な機能が正常に動作していることを確認するための疎通テストが含まれています。疎通テストは、コードの改修や変更後に、主要な機能が引き続き正しく動作していることを迅速に確認するために使用します。

## 目的

1. システムの主要コンポーネントが基本的に機能していることを確認する
2. 改修時のデグレードを素早く検出する
3. CI/CDパイプラインの最初のステップとして使用する
4. 本格的な統合テストや総合テストの前に実行する前提条件チェックとして機能する

## テスト構成

以下の主要コンポーネントに対する疎通テストを実装しています：

1. **データベース接続** (`test_db_connection.py`): データベースへの基本的な接続と操作が機能するかを確認
2. **APIエンドポイント** (`test_api_endpoints.py`): 主要なAPIエンドポイントが応答するかを確認
3. **エージェント基本機能** (`test_agents_basic.py`): 各エージェントの基本的な機能が動作するかを確認
4. **ワークフロー初期化** (`test_workflow_init.py`): ワークフローの初期化処理が正常に動作するかを確認

## 実行方法

疎通テストのみを実行するには、以下のコマンドを使用します：

```bash
pytest tests/smoke_tests -v
```

特定の疎通テストのみを実行するには：

```bash
pytest tests/smoke_tests/test_db_connection.py -v
```

## 注意事項

- 疎通テストはシステムの詳細な機能を検証するものではなく、基本的な機能が動作していることのみを確認します
- テスト実行時間は短く（1分以内を目標）、頻繁に実行できるように設計されています
- 失敗した場合は、より詳細なテストを実行する前に問題を解決する必要があります
