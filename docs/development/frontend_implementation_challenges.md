## API実装状況と使用方法

### 1. ダッシュボードAPI
- `/api/dashboard/system-status` - システム全体のステータスを取得
- `/api/dashboard/workflow-trends` - ワークフローの傾向データを取得
- `/api/dashboard/agent-performance` - エージェントのパフォーマンス統計を取得
- `/api/dashboard/task-distribution` - タスク分布を取得
- `/api/dashboard/workflow-status-summary` - ワークフローステータス概要を取得
- `/api/dashboard/chart/workflow-status` - ワークフローステータスチャートデータを取得
- `/api/dashboard/chart/time-series/{metric}` - 時系列チャートデータを取得
- `/api/dashboard/chart/audit-progress/{audit_id}` - 監査進捗状況を取得
- `/api/dashboard/chart/summary-metrics` - 概要メトリクスを取得

### 2. ファイル管理API
- `/api/files` - ファイル一覧を取得
- `/api/files/{file_id}` - ファイル詳細を取得
- `/api/files/{file_id}/download` - ファイルをダウンロード
- `/api/files/{file_id}/metadata` - ファイルメタデータを更新
- `/api/files/upload` - ファイルをアップロード
- `/api/files/reports/{workflow_id}` - 監査レポートを取得
- `/api/upload/upload-simple` - シンプルなファイルアップロード

### 3. バッチ処理API
- `/api/batch/agents` - エージェントの一括操作
- `/api/batch/tasks` - タスクの一括操作
- `/api/batch/workflows` - ワークフローの一括操作
- `/api/batch/jobs/{job_id}` - ジョブ状態を取得
- `/api/batch/jobs/{job_id}/results` - ジョブ結果を取得
- `/api/batch/jobs/{job_id}/cancel` - ジョブをキャンセル
- `/api/batch/import/{entity_type}` - エンティティをインポート
- `/api/batch/export/{entity_type}` - エンティティをエクスポート
- `/api/batch/exports/{job_id}/download` - エクスポートファイルをダウンロード

### 4. 通知API
- WebSocketエンドポイント: `/api/notifications/ws/{user_id}` - リアルタイム通知の受信
- `/api/notifications/send` - 通知を送信
- `/api/notifications/topics` - アクティブな通知トピックを取得

### 5. エラー管理API
- `/api/errors/report` - エラーレポートを送信
- `/api/errors/{error_id}` - エラー状態を確認
