# 内部監査AIエージェントシステム

## 全体処理フロー

1. **初期設定・準備フェーズ**
   - 被監査部門から25件のサンプルファイルを受領
   - エージェントAが検証基準と判断ルールを定義
   - 利用可能な補助ツールのライブラリを登録

2. **サンプル単位の処理サイクル**
   - 各サンプルごとに検証サイクルを実行
   - **不明点発生時の対応手段を階層的に選択**:
     1. 補助ツールでの解決を試行
     2. 必要に応じて追加データの要求
     3. それでも解決しない場合のみ、人間への質問

## エージェント間のやり取り詳細 - ツール活用版

### エージェントA → エージェントB（通常の指示）

```markdown
【エージェントA】1件目の指示発行
「サンプルID-001の出張精算書類3点を検証してください。出張申請書、領収書キャプチャ、精算承認画面を照合し、金額、日付、承認者情報の整合性を確認してください。判断基準は以下の通りです：
- 出張期間と領収書日付の整合性
- 申請金額と領収書金額の一致
- 承認者の適切性（権限者による承認）
...」
```

### エージェントB → エージェントA（不明点と対応策の提案）

```markdown
【エージェントB】1件目の課題と対応策提案
「サンプルID-001の領収書キャプチャに関して以下の課題があります：
1. 領収書上の印影が不鮮明で真正性の確認が困難
2. 承認者の署名が判読しづらく、適切な権限者か確認できない

対応策として提案します：
1. 印影部分の画像拡大処理を実行し、細部確認
2. 承認者名を社員マスタと照合して権限確認
これらのツールを実行してよろしいでしょうか？」
```

### エージェントA → エージェントB（ツール実行の承認）

```markdown
2. 承認者名「山田太郎」について社員マスタと照合し役職確認

```
