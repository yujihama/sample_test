# ソースコード構成ガイド

このディレクトリには内部監査AIエージェントシステムのソースコードが格納されています。
各サブディレクトリはシステムの特定の側面を担当しており、以下にその概要を説明します。

## ディレクトリ構成

```
src/
├── agents/       - AIエージェント実装
├── api/          - REST API実装
├── core/         - コア機能と共通基盤
├── models/       - データモデルとリポジトリ
├── prompts/      - LLMのプロンプトテンプレート
├── scripts/      - ユーティリティスクリプト
├── services/     - ビジネスロジック
├── tools/        - 補助ツール実装
└── utils/        - ユーティリティ関数
```

## 主要コンポーネント

### エージェント (`agents/`)

複数のAIエージェントが協調して監査タスクを実行します。

- **agent_a.py**: 監査手続き理解・設計エージェント
- **agent_b.py**: サンプル検証実行エージェント
- **agent_c.py**: 結果集約エージェント
- **agent_d.py**: 報告書作成エージェント

各エージェントは特定の役割を持ち、`AgentBase`クラスを継承して実装されています。
ユースケースにおける「エージェントA→エージェントB（通常の指示）」のようなやり取りは、
これらのエージェント間のメッセージングによって実現されています。

### 補助ツール (`tools/`)

エージェントが活用できる様々なツールを実装しています。

- **image_processor.py**: 印影検出・画像処理
- **data_validator.py**: データ照合・検証
- **excel_analyzer.py**: Excelデータ解析
- **document_parser.py**: 文書解析
- **tool_registry.py**: ツール登録・管理

ユースケースの「エージェントB→画像処理ツール（実行要求）」のようなやり取りは、
ここで実装されたツールとツールレジストリを通じて行われます。

### コア機能 (`core/`)

システムの基盤となる共通機能を提供します。

- **agent_base.py**: エージェント基底クラス
- **tool_base.py**: ツール基底クラス
- **workflow.py**: ワークフロー管理
- **messaging.py**: エージェント間通信
- **context_manager.py**: コンテキスト管理

### データモデル (`models/`)

データベースモデルとリポジトリパターンの実装です。

- **schema.py**: Pydanticモデル
- **database.py**: データベース接続
- **repositories/**: リポジトリクラス

### API (`api/`)

外部とのインターフェースを提供するRESTful APIです。

- **main.py**: FastAPIアプリケーション
- **routes/**: エンドポイント定義
- **dependencies.py**: 依存関係注入

## エントリーポイント

- **main.py**: アプリケーションのメインエントリーポイント

## 拡張方法

### 新しいエージェントの追加

1. `src/agents/`に新しいエージェントファイル（例: `agent_e.py`）を作成
2. `AgentBase`を継承したクラスを実装
3. 必要なメッセージハンドラを実装
4. `config.py`に新しいエージェントのIDを追加
5. 既存のワークフローに統合するか、新しいワークフロータイプを作成

### 新しいツールの追加

1. `src/tools/`に新しいツールファイルを作成
2. `ToolBase`を継承したクラスを実装
3. `execute()`メソッドに主要な機能を実装
4. `config/tools_config.yaml`に設定を追加
5. 必要に応じてエージェントにツール利用のヘルパーメソッドを追加

### 既存機能の拡張

- **エージェント機能拡張**: 該当する`agent_*.py`ファイル内にメソッドを追加
- **ツール機能拡張**: 該当するツールクラスに新しい操作タイプ（capability）を追加
- **ワークフロー拡張**: `workflow.py`に新しいワークフロー定義を追加

## ユースケースとの関連

ユースケースで示されている「エージェント間のやり取り」や「ツール活用」は以下のように実装されています：

1. **エージェント間通信**: `messaging.py`を介したメッセージ送受信
2. **ツール実行**: `tool_registry.py`を介したツール呼び出し
3. **サンプル検証**: エージェントBの`execute_test_items()`による検証実行
4. **報告書作成**: エージェントDによる結果の集約と報告書生成

詳細については各コンポーネントのREADMEを参照してください。
